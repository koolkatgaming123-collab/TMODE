PRIORITIES
The endgame objective is sustainable frame budgets and fewer slow frames, not
the highest unloaded average or lowest process count. Example arithmetic only:
240 FPS has a 4.17 ms budget. A 10 ms simulation spike is not fixed by the GPU
finishing in 2 ms. CPU work, GPU queueing, compilation/asset stalls, memory
pressure, thermals and network queues need different diagnosis.
1. Stability/firmware and required CPU provisioning before aggressive clocks.
2. Establish the actual constraint using representative, warmed data.
3. Compare native latency controls, sustainable cap and intended display path.
4. Reduce measured competing work while preserving dependencies.
5. Retain repeatable improvements with an exact recovery path.
