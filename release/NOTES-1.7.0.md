TMODE 1.7.0 introduces the optimization station UI and a reviewed, reversible preparation flow.

- **Tweak PC:** hardware and current-state analysis drives supported Windows, Fortnite settings and power changes. A newly created and verified Windows restore point is mandatory before application; exact per-setting recovery journals remain available.
- **Strip Windows ⚠:** eight optional feature groups, no uninstalling, explicit loss review, individual repairs such as Fix Printing, and Repair All.
- **Internet Optimizer:** bounded wired NIC/RSS candidates derived from topology and driver support; repeated A/B/A measurements with original settings restored between trials. Apply is a separate choice.
- **Experimental:** optional wired latency, DSCP and measured background-priority switches begin off.
- **Guide / BIOS:** hardware-specific sourced advice, with firmware changes left manual.
- **Signed updates:** the same executable can discover, verify, download and install future remote GitHub releases with an explicit restart decision and recovery guards.
- **Embedded licenses:** exact runtime and optional-helper notices are available from Updates, including in the standalone EXE.

The Internet goals are equally weighted ping, local processing latency and stability/jitter/loss. Native ICMP measurements do **not** measure NIC processing latency. It stays Unknown; only a separately consented provisional ping/stability result can be applied without it. Calibration is outside Fortnite and does not establish server ping, crowded-endgame behavior or end-to-end input latency.

O&O ShutUp10++ assistance uses a separately obtained verified vendor GUI. This release does not bundle O&O or silently apply a guessed Recommended preset.

See the included validation record for isolated checks and hidden UI review. No live PC tuning or Fortnite benchmark was run to validate 1.7.0, and no universal FPS or latency gain is promised.
