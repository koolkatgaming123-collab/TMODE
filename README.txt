TMODE 1.7.0 — COMPETITIVE OPTIMIZATION STATION

Windows x64 portable app. The .NET 10 desktop runtime is bundled; no account,
AI subscription, Native or second PC is needed. Open TMODE.exe from the release,
or Tourney Mode.exe from the portable ZIP. Run as administrator when applying
changes. Opening the app does not activate optimization or run network trials.

GET STARTED
1. Close Fortnite. Open Tweak and choose your performance goal, activity and
   power preference. Higher-power choices require explicit heat acceptance.
2. Choose Tweak PC. It scans this PC, explains evidence and opens an exact
   change review. Accept the review to apply supported changes.
3. TMODE creates AND verifies a new Windows restore point before any Tweak
   write. If System Protection is disabled, Windows refuses a new point, or
   its creation limit is reached, application stops before performance writes.
4. Read the per-feature results. Some changes need a browser restart, sign-out
   or next game launch. Launch Fortnite yourself when ready.

The local policy engine orchestrates a finite set of supported actions. It
does not upload your PC inventory to an AI service or execute generated code.
Tweak PC applies eligible differences in Windows Game Mode/capture, twelve
Windows preference/policy requests, supported existing Fortnite settings and
explicit power options. Managed policies and unknown values are preserved.
Hardware alone does not establish a universally optimal FPS cap or power plan.
Keep your cap/resolution unless you explicitly choose otherwise. Renderer and
NVIDIA Reflex remain manual in-game choices; no guessed console variables.

STRIP WINDOWS (CAUTION)
This separate page disables selected optional functions; it uninstalls nothing.
Review current service state and accept the listed functionality losses first.
Eight groups cover printing, search indexing, Xbox online functions, maps,
media sharing, network discovery, optional diagnostics and scanning. Active
dependents, print jobs and game presence can block a group. Security, Windows
Update, drivers, audio, input, networking and anti-cheat are not stripped.
Fix Printing and the other individual repair buttons restore that group's
recorded startup/delayed/running state. Repair All handles all recorded groups.

INTERNET OPTIMIZER
Explicitly started, bounded experiments on a supported physical wired route.
A verified restore point and durable exact NIC/RSS originals precede trials.
Quick and Thorough modes compare supported RSS allocations/profiles,
interrupt moderation and Energy Efficient Ethernet with repeated A/B/A periods.
CPU topology, driver capabilities and queue limits constrain each candidate.
Originals are restored after every treatment and on cancellation where safe.
If Fortnite starts or identity/driver/route changes, further work stops and
unrestored originals stay in the recovery journal. No adapter reconnect during
Fortnite is allowed. HTTPS comparison traffic is optional and OFF by default.

The three goals have equal weight: ping, traced local processing latency and
stability (jitter/packet loss). This version's native ICMP capture cannot measure
actual NIC processing latency. Gateway RTT and CPU/DPC percentages are not
substitutes. Thus its normal strict result can retain the baseline even when
ping improves. A separately enabled provisional choice can apply a repeatable
ping/stability result with that missing evidence disclosed. Apply is separate
from calibration; no winner is applied automatically. Tests cover only the
bounded candidates and targets: they cannot promise absolute best internet,
Fortnite-server ping, crowded-endgame behavior or click-to-photon latency.

EXPERIMENTAL / GUIDE
Three OFF-default switches request a supported wired latency preset, outbound
DSCP46 mark or measured known-app Below Normal governor for the next reviewed
Tweak run. Less interrupt batching can consume more CPU; routers may ignore
DSCP. Experiments are requests, not measured improvements. Guide / BIOS uses
observed CPU, board and firmware facts for sourced manual advice, including
vendor defaults/firmware, memory stability, graphics, Reflex, cooling and
measurement. No firmware flashing, voltage/clock changes, security disabling,
blanket timer/BCD hacks or arbitrary IRQ/affinity writes are performed.

TOURNEY / RECOVERY
The Overview and Apps pages retain reviewed process cleanup, keep protections,
Fortnite priority and quiet-match controls. Ordinary closed apps stay closed on
OFF; recorded supported Codex components can return. Game dependencies,
security, audio/input, kept/foreground/capture/routing paths remain protected.
Realtime priority and anti-cheat bypasses are never used. Process-count or FPS
targets are not guaranteed. Tweak PC itself does not close apps or Native.

Restore changes / Ctrl+Alt+F11 restores the recorded originals. Recovery can
wait for Fortnite to exit. Exact journals are separate from Windows restore
points and preserve conflicting external edits instead of blindly overwriting
them. Keep %LOCALAPPDATA%\TourneyMode\session.json until recovery completes.
Tweak/Strip/Internet startup opens recovery rather than silently undoing your
persistent preferences. Use Repair for a stripped feature or Restore changes
for the complete active transaction before starting a different workflow.
Never delete a journal or replace a running EXE to force an upgrade.

UPDATES
The same EXE checks a remote GitHub release feed while idle. Downloads and
restart/install require your choice. RSA-signed manifests, HTTPS allowlisted
redirects, exact version/architecture/size/SHA256 and PE metadata protect the
download. Apply waits for normal parent exit, refuses game/pending recovery,
uses atomic replacement and retains a backup with rollback on detected failure.
An update signature is separate from Windows Authenticode code signing.
Existing 1.5/1.6 copies need a one-time move to this updater-enabled release.

DIAGNOSTICS / VALIDATION
Optional frame capture uses official Intel PresentMon 2.6.0 from Tools; CSV
import works without it. No capture, benchmarks or network trials start merely
by opening the app. See VALIDATION.txt for this release's actual checks and
limits. No live FPS, endgame, latency or NIC benefit is established by fixture
tests or hidden UI screenshots.
